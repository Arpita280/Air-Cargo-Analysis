# Air-Cargo-Analysis
Air Cargo Analysis SQL Project — ERD, SQL Queries, Stored Procedures, Views, Indexing, and Performance Optimization.

A complete SQL-based analysis of airline operations, passenger behavior, ticket sales, and route performance.
This project was completed as part of the Simplilearn SQL Training Course-End Project.

## Project Overview
This project analyzes Air Cargo’s operational data to:
Identify the busiest routes
Find regular customers
Analyze ticket sales & revenue
Improve travel experience & operational efficiency
The project uses SQL queries, joins, constraints, indexing, views, stored procedures, functions, window functions, and cursors.

##  Dataset Description
#### 1. customer
Contains customer personal details.

#### 2. passengers_on_flights
Contains flight travel details of each passenger.

#### 3. ticket_details
Contains ticket purchase information, pricing, and airline brand.

#### 4. routes
Contains route-level information such as origin, destination, and distance.
